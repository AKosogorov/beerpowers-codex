# Команды BeerPowers

Обрабатывай только сообщение, которое начинается с отдельного слова `$beerpowers` или ссылки Codex на выбранный навык `beerpowers`. Следующее слово задаёт имя команды. Если имени нет, покажи доступные варианты. Упоминание команды в вопросе, цитате или примере не запускает её.

Подтверди [установку пакета и выбери Perl](../../reference/command-runtime.md "beerpowers:reference/command-runtime.md"). Передай [маршрутизатору](../../bin/command-route.pl) одним аргументом префикс `$beerpowers <имя>`, используя имя команды из сообщения. В PowerShell и POSIX shell передавай префикс в одинарных кавычках. Если имя содержит символы кроме строчных ASCII букв, цифр и дефисов, передай только `$beerpowers` и покажи доступные варианты. Остальные аргументы сохраняй из сообщения дословно, учитывая порядок флагов, пробелы и текст постановки.

Ссылка на справочник открывает Markdown-файл. В подсказке ссылки указан адрес `beerpowers:reference/<имя>.md` для команды `Read` из установленного пакета. Суффикс `#раздел` указывает на заголовок документа.

При `status: route` открой Markdown по полю `path` относительно корня выбранного пакета и следуй инструкции с исходными аргументами. При `status: help` покажи поле `commands`, при неизвестном имени назови его. При `status: ignored` продолжай обычную работу.
