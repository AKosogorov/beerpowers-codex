# Решения о работе команды

Порядок приёма задачи и выбора checkpoint описан в [intake-протоколе](intake-protocol.md).

## Цена ролевого захода

Уровень выбирай для конкретного захода. Подними reasoning effort, когда ошибку сложно заметить машиной, роль принимает решение или её результат используется другими ролями. Снизь effort для однозначного исполнения с полной машинной проверкой. Назови фактический выбор и основание перед вызовом.

При доступном параметре `model` выбирай быстрый вариант для разведчика и механической работы, если результат полностью проверяется машиной, исполнитель не выбирает механизм и результат не запускает другие роли. Архитектурный дизайн, ревью, денежные операции, миграции данных и публичный контракт требуют наиболее надёжной доступной модели. Передавай `reasoning_effort` только с поддерживаемым значением. При отсутствии параметра действует модель сессии. Возобновление роли сохраняет настройки первоначального вызова. Изменение модели или effort требует нового запуска.

Разведчик получает задачу поиска, разрешённые пути и критерий отчёта. Рабочие записи разведчику запрещены. Проверяй отсутствие его записей через status/diff.

Для ограничения расходов применяй [навык economy](../skills/economy/SKILL.md).
