# Сводка задач для ретроспективы

Из корня внешнего workspace запусти `node retro.mjs status [TASK ...] [--fetch] [--remote]`, передав путь к `bin/retro.mjs` из пакета. [Команда ретроспективы](../commands/retro.md)

Без кодов обработчик перечисляет папки в `memory/tasks/`, включая вложенные коды вида `fix/example` и задачи, у которых сохранились только материалы трекера, скриншоты или экспорт Figma. `artifacts` считает файлы в папке задачи и показывает, сколько из них менялись за последние 30 дней. Симлинки и junctions пропускаются. `missingProducts` показывает отсутствующие репозитории из сохранённого состава задачи.

Для каждого продукта сводка показывает SHA точной локальной ветки и локально сохранённой ссылки origin. `targets` перечисляет базу задачи и известную ветку origin по умолчанию с их SHA. Влитость определяется по предкам или эквивалентным патчам. `merged: null` означает, что отсутствует локальная ветка или пригодная цель сравнения.

- Без флагов используются локальные ссылки Git.
- Для каждого продукта `lastFetchAt` показывает время изменения непустого `FETCH_HEAD` этого checkout (UTC). Git сам определяет путь, в том числе для связанного рабочего дерева. `freshness` принимает значения `fresh` (до суток включительно), `stale` (старше суток), `unknown` (наблюдение отсутствует). Это время последнего наблюдаемого fetch, который мог касаться другого remote или части веток. Проверка через `--remote` сама по себе не обновляет этот файл.
- `--fetch` запрашивает сервер, обновляет ссылки `origin/*`, удаляет устаревшие ссылки origin и устанавливает локальную `origin/HEAD` по ответу сервера. Рабочие файлы задачи и локальные ветки сохраняются.
- `--remote` заполняет `remoteBranch` по объявленным сервером точным именам веток. `false` означает отсутствие ветки в ответе сервера. `null` означает отсутствие проверки или ответа. Ошибки сетевых операций видны в `products[].problems`.

Сводка помогает выбрать задачи для разбора. Для уборки артефактов нужен `retro plan` со свежим доказательством влитости и проверкой содержимого папки. [Порядок уборки](../commands/retro.md#план-уборки-и-решение-владельца)
