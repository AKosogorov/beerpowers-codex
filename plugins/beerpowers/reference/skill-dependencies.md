# Зависимости навыков ролей

Тимлид открывает эту таблицу при [setup](../commands/setup.md#внешние-навыки-и-интеграции) и [doctor](../commands/doctor.md). Сопоставь найденный стек, назначение роли и список навыков текущего чата. Подтверждённые назначения записываются в поле `skills` конфигурации роли. Для отсутствующего навыка покажи роль, причину и способ подключения. Передавай роли применимые навыки из `role-packet`. Шаблоны `*-agent.md` поставляются как Markdown-брифы для Codex Desktop.

| Навык | Роли | Когда предлагать | Если недоступен |
|---|---|---|---|
| `superpowers:test-driven-development` | tester | При написании теста на новый или исправленный сценарий | Проверь красный и зелёный прогон по брифу тестера |
| `karpathy-guidelines` | architect, backend, frontend, reviewer | Неоднозначная постановка, допущения или неясный критерий готовности | Назови допущения и сформулируй проверяемую цель |
| `caveman` | все | Если команда выбрала сжатый стиль отчётов | Сохрани форму отчёта из устава |
| `caveman-review` | reviewer | Краткий формат замечаний в ревью | Используй форму из брифа ревьюера |
| `laravel-specialist` | backend, database | Laravel, особенно Eloquent, API Resources и миграции | Используй [пресет Laravel](../templates/roles/presets/laravel/) |
| `php-pro` | backend, database | PHP с подтверждённой версией и совместимым стеком | Сверяй Composer и конфигурацию анализа проекта |
| `nuxt` | frontend | Nuxt, подтверждённый манифестом | Используй [пресет Nuxt](../templates/roles/presets/nuxt/) |
| `nuxt-ui` | frontend | Подтверждённый `@nuxt/ui` | Сверяй компоненты по источникам и версии проекта |

Подробные поводы для строк слота `SKILLS_GUIDE` даны в [пресетах](../templates/roles/presets/skills.md). Навыки самого BeerPowers приходят с плагином. Для ревью безопасности передай роль и дифф конкретного проекта по уставу, так как корень внешнего workspace содержит настройки команды.
