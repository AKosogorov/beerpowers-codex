# Память роли

Открой этот индекс при каждом назначении роли. Прочитай перечисленные здесь поправки, относящиеся к текущему заданию. Каталог принадлежит роли, в которой получена обратная связь.

Сохраняй только явную обратную связь человека о работе этой роли. Каждая поправка — отдельный `feedback_<тема>.md` рядом с индексом. Укажи дату, точную цитату или ссылку на неё, контекст применения и ожидаемое поведение. Добавь в индекс ссылку и краткий повод прочитать её. При уточнении сохрани историю смысла и обнови указатель. Вывод самого агента не является обратной связью человека.

Проектные правила, факты о коде и результаты проверок размещаются по индексу `memory/MEMORY.md`. Состояние задачи, SHA, временные заметки и передача между фазами принадлежат папке задачи.
