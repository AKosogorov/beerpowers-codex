| Роль | Уровень | Пример захода |
|---|---|---|
| `architect` | `xhigh` | ADR и design brief новой фичи, развилка границ модулей |
| | `max` | решение, задевающее деньги или контракт API |
| | `medium` | консультация «куда положить X» по готовой раскладке |
| `backend` | `high` | новый сервис прикладного слоя, правка бизнес-логики, нетривиальный баг |
| | `medium` | фикс по замечанию ревью с указанным местом, экран админки по образцу |
| | `xhigh` | всё, что касается денег |
| `database` | `xhigh` | миграция, меняющая существующие данные; смена маппинга поискового индекса |
| | `high` | новая таблица или индекс, разбор медленного запроса |
| `frontend` | `high` | новая страница или компонент с состоянием, баг вёрстки без очевидной причины |
| | `medium` | вёрстка по макету по образцу соседнего компонента |
| `tester` | `high` | тест-план и тесты эпика, локализация плавающего бага |
| | `medium` | перепроверка затронутых сценариев после фикса, новые скриншоты |
| `reviewer` | `high` | ранний проход и повторный проход по инкременту `HEAD~1` |
| | `xhigh` | финальный проход с вердиктом `APPROVED` |
| | `max` | финальный проход money-critical диффа |
| `explorer` | `low` | «где определено X», «что ссылается на Y» |
| | `medium` | поиск по нескольким соглашениям имён и репозиториям |
| `devops` | `medium` | правка стадии CI, переменной окружения, Dockerfile |
| | `high` | деплой-гейт, разбор падения пайплайна без очевидной причины |
| `auditor` | `xhigh` | security- или perf-аудит перед релизом |
| | `high` | архитектурный обзор на углубление модулей |
| `product` | `high` | intake, PRD и сводка оценок |
| | `medium` | правка готового документа по замечаниям |
| независимый оппонент | `xhigh` | stress-test ADR, money-critical дифф |
