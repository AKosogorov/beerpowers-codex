## Границы инструкций и памяти

Команда начинает работу из внешнего workspace. В Codex точка входа команды — корневой `AGENTS.md`, в Claude Code — корневой `CLAUDE.md`, если он поддерживается командой. Каждый checkout в `projects/` и `worktrees/` — отдельный Git-репозиторий. При прямом запуске из него сверь, какие инструкции загрузил инструмент, и явно подключи устав внешнего workspace для задач команды.

Codex строит цепочку от определённого корня проекта до рабочего каталога и в каждой папке выбирает `AGENTS.override.md`, `AGENTS.md` или настроенное резервное имя. Claude Code загружает `CLAUDE.md` по своей цепочке и при входе в область вложенных файлов. Команда переносит действующие локальные правила в инструкции их проекта. Исключения вложенных файлов настраиваются и проверяются отдельно для каждого инструмента.

Команда хранит проектные знания в общей папке `memory/` и не использует для них автопамять Claude Code или Codex. Настройки автопамяти каждого хоста проверяются отдельно.
