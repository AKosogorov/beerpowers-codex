# Команды, которые выполняет человек

Бери оболочку из окружения текущего чата. Если пользователь может работать в нескольких оболочках, подпиши выбранную или дай варианты для каждой. Команду показывай в отдельном блоке с тегом оболочки, без приглашения и вывода.

Для Windows PowerShell 5.1 учитывай синтаксис кавычек, переменных и отсутствие `&&`. При вызове скрипта Git Bash из PowerShell укажи исполняемый файл Git for Windows. В Git Bash используй POSIX-пути и кавычки его оболочки.
