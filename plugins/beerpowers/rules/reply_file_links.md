# Ссылки на файлы для пользователя

Для файла рабочего каталога дай кликабельную Markdown-ссылку с понятным названием. Codex Desktop использует абсолютный путь, прямые слэши и при необходимости суффикс `:строка`. Путь с пробелами заключи в угловые скобки внутри адреса ссылки. Для таблицы допустимо короткое имя файла.

Для внешнего пути используй форму, которую поддерживает клиент. Если файл недоступен в его просмотрщике, напиши путь в обратных кавычках. Так же оформляй путь Windows с обратными слэшами.
